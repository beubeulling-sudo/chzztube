치지직 → 유튜브 자동 업로드

치지직 다시보기가 올라오면 자동으로 받아서, 길이와 재생 상태를 검증한 뒤 내 유튜브 채널에 올려 주는 윈도우 프로그램입니다.

목차
  1. 준비물
  2. 설치
  3. 구글 API 파일 만들기 (처음 한 번, 10분)
  4. 프로그램 시작 가이드 따라 하기
  5. 과거 방송도 올리기 (순서 지키기)
  6. 7일마다 유튜브 인증
  7. 화면 보는 법
  8. 자동 실행은 언제 도나
  9. 문제가 생겼을 때
  10. 꼭 지킬 것

1. 준비물

  • 윈도우 10 또는 11 PC와 인터넷 연결.
  • 디스크 여유 공간 100GB 이상. 6시간 방송 한 편이 약 25GB이고, 12시간이 넘는 방송은 잠깐 그 두 배를 씁니다. 파일은 업로드가 끝나면 자동으로 지워집니다.
  • 유튜브 채널이 있는 구글 계정. 채널이 없으면 youtube.com에서 오른쪽 위 프로필 → '채널 만들기'로 먼저 만드세요.
  • 유튜브 채널 전화 인증(youtube.com/verify). 15분이 넘는 영상 업로드와 썸네일 적용에 필요합니다.
  • (선택) 19+ 방송도 받으려면 성인 인증된 네이버 계정.

2. 설치

  1. 받은 zip 파일을 OneDrive 밖의 폴더에 풉니다. 예: C:\chzzk2yt
    바탕화면이나 문서 폴더는 OneDrive와 동기화되는 경우가 많습니다. 수십 GB 영상이 같이 동기화되면 느려지고 오류가 날 수 있습니다.
  2. 폴더 안의 menu.bat을 더블클릭합니다. 처음 실행하면 필요한 것을 자동으로 설치합니다(5~10분).
    • "Windows의 PC 보호" 창이 뜨면 추가 정보 → 실행을 누르세요.
  3. 설치가 끝나면 프로그램이 자동으로 열리고, 바탕화면에 바로가기 두 개가 생깁니다.
    • 치지직→유튜브 (프로그램·권장): 프로그램 화면. 평소에는 이것만 쓰면 됩니다.
    • 치지직→유튜브 (명령창 메뉴): 검은 명령창에서 번호로 고르는 고급 메뉴(설치·업데이트 등). 보통은 쓸 일이 없습니다.
  4. 처음 열면 시작 가이드 창이 뜹니다. 채널 추가(1단계)는 바로 할 수 있고, 2단계에서 필요한 구글 API 파일은 아래 3장대로 만드세요.

3. 구글 API 파일 만들기 (처음 한 번, 약 10분)

프로그램이 내 유튜브 채널에 영상을 올리려면 구글이 발급하는 '열쇠 파일'(client_secret.json)이 필요합니다. 무료이고, 유튜브 채널이 있는 본인 구글 계정으로 한 번만 만들면 됩니다.

이 파일과 프로그램 폴더의 data 폴더는 남에게 주지 마세요. 내 채널에 영상을 올릴 수 있는 권한이 들어 있습니다. 이 과정을 캡처할 때도 '클라이언트 보안 비밀번호'가 보이는 화면은 공유하지 마세요.

1프로젝트 만들기

  1. console.cloud.google.com에 접속합니다. 처음이면 약관에 동의합니다.
  2. 왼쪽 위 프로젝트 선택 → 새 프로젝트를 누릅니다.
  1. 프로젝트 이름은 아무거나 넣고(예: chzzk2yt), 상위 리소스는 '조직 없음' 그대로 둔 채 만들기를 누릅니다.
  2. 오른쪽 위 종 모양 알림에 '프로젝트 만들기' 완료가 뜨면 프로젝트 선택을 누릅니다. 위쪽에 방금 만든 프로젝트 이름이 보이면 됩니다.

2YouTube API 켜기

  1. 왼쪽 메뉴(☰) API 및 서비스 → 라이브러리로 갑니다.
  2. 검색창에 YouTube Data API v3를 입력하고 결과를 누릅니다.
  3. 사용을 누릅니다.

3동의 화면(Google 인증 플랫폼) 만들기

  1. 왼쪽 메뉴 API 및 서비스 → OAuth 동의 화면으로 가서 시작하기를 누릅니다.
  2. 네 단계를 차례로 채웁니다.
    • 앱 정보: 앱 이름은 아무거나(예: chzzk2yt. 'Google', 'YouTube'라는 단어는 넣지 마세요). 사용자 지원 이메일은 본인 이메일을 고릅니다.
    • 대상: 외부를 고릅니다.
    • 연락처 정보: 본인 이메일을 넣습니다.
    • 완료: 정책 동의에 체크하고 만들기를 누릅니다.

4테스트 사용자에 내 계정 넣기 (빠뜨리면 '403 access_denied' 오류)

  1. 왼쪽 메뉴 대상을 누릅니다.
  2. 아래쪽 테스트 사용자 → + Add users를 누릅니다.
  3. 유튜브에 올릴 구글 계정 이메일을 넣고 저장을 누릅니다.

같은 화면의 '게시 상태: 테스트 중'과 '앱 게시' 버튼은 건드리지 않아도 됩니다. 테스트 상태로 쓰고, 대신 7일마다 인증을 한 번 해 주면 됩니다(6장).

5열쇠 파일(JSON) 받기

  1. 왼쪽 메뉴 클라이언트 → 위쪽 + 클라이언트 만들기를 누릅니다.
  2. 애플리케이션 유형은 반드시 데스크톱 앱을 고릅니다. 이름은 그대로 두고 만들기를 누릅니다.
  3. 'OAuth 클라이언트 생성됨' 창이 뜨면 맨 아래 JSON 다운로드를 누릅니다. 다운로드 폴더에 client_secret_….json 파일이 생깁니다.
    • 이 창을 닫으면 JSON을 다시 받을 수 없습니다. 놓쳤다면 클라이언트를 하나 더 만들면 됩니다.
설정이 구글 쪽에 적용되기까지 몇 분 걸릴 수 있습니다. 바로 다음 단계에서 오류가 나면 5분쯤 뒤에 다시 해 보세요.

4. 프로그램 시작 가이드 따라 하기

프로그램 오른쪽 위 시작 가이드 버튼으로 언제든 다시 열 수 있습니다. 단계가 끝나면 ⬜가 ✅로 바뀝니다.

단계하는 일
1. 채널 추가채널 관리… → 치지직 채널 주소(https://chzzk.naver.com/…)를 붙여 넣고 추가 → 저장을 누릅니다. 시작은 기본값 new(지금 이후 올라오는 방송부터)로 두세요. 과거 방송은 5장의 방법으로 따로 가져옵니다.
2. 구글 API 파일파일 선택…을 누르고 3장에서 받은 client_secret_….json을 고릅니다. "바로 유튜브 인증을 할까요?"가 뜨면 Yes를 누릅니다.
3. 유튜브 인증브라우저가 열리면 채널 계정으로 로그인합니다. 'Google에서 확인하지 않은 앱' 화면이 나오면 계속을 누릅니다. 권한 화면에서는 모두 선택(체크) → 계속을 누릅니다. 본인이 만든 앱이라 이 경고는 정상입니다. 채널이 여러 개인 계정이면 올릴 채널을 고르세요.
끝나면 아래 '작업 출력'에 유튜브 인증 완료: (채널 이름)과 만료 예정일이 나옵니다.
4. 업로드 방식
  • 재생목록 선택…: 영상을 넣을 기본 재생목록을 고릅니다. 재생목록은 유튜브 스튜디오에서 먼저 만들어 두세요.
  • 채널이 여러 개면 채널마다 다른 재생목록에 넣을 수 있습니다. 관리 → 채널 관리에서 채널을 고르고 선택 채널 재생목록 지정…을 누르세요. 지정하지 않은 채널은 기본 재생목록으로 들어갑니다.
  • 설정…: 공개 범위(공개 / 일부 공개 / 비공개)를 고릅니다. 기본은 공개입니다.
5. 네이버 로그인 (선택)19+ 방송까지 받으려면 필요합니다. 뜨는 브라우저 창에서 네이버에 로그인하고 창을 닫으면 됩니다. 이후 로그인은 자동으로 유지됩니다.
6. 드라이런 (권장)실제로 받거나 올리지 않고 점검만 합니다. 아래 '작업 출력'에 오류가 없으면 준비 완료입니다.
7. 자동 실행 켜기자동 실행 등록을 누르면 30분마다 새 다시보기를 확인해서 받고 올립니다.
8. 과거 방송 (권장)채널 추가 전에 올라온 방송도 올리고 싶으면 과거 방송 가져오기…를 누릅니다. 다음 장을 보세요.

5. 과거 방송도 올리기 (순서 지키기)

채널을 추가하면 이미 올라와 있던 다시보기가 목록에 '보류(자동 대상 아님)'로 표시됩니다. 이 방송들은 자동으로 올라가지 않습니다.

하나씩 우클릭 → '받기'로 넣으면 유튜브 업로드 순서가 방송일과 달라질 수 있습니다. 예를 들어 최신 방송이 먼저 올라가고 옛날 방송이 나중에 올라가는 식입니다.
  1. 시작 가이드 8단계나 관리 → 과거 방송 가져오기 (순서대로)…를 엽니다.
  2. 목록은 오래된 순입니다. 올리기 시작할 가장 오래된 방송 하나를 클릭합니다.
  3. 대기열에 추가를 누르면 그 방송부터 최신 방송까지 전부 대기열에 들어갑니다. 이후 방송일 순서대로 한 편씩 받고 올립니다. 새로 올라오는 방송은 그 뒤에 이어서 처리됩니다.
  • 한 편에 30분~1시간 정도 걸립니다. 방송이 많으면 며칠에 걸쳐 올라갑니다.
  • 디스크는 한 편씩만 씁니다.
  • 유튜브 하루 업로드 한도에 걸리면 다음 날 자동으로 이어서 올립니다.
  • 가장 좋은 방법은 자동 실행을 켜기 전에 과거 방송을 먼저 넣어 두는 것입니다. 이미 최신 방송이 올라간 뒤에 과거 방송을 넣으면, 유튜브 업로드 순서는 그 뒤가 됩니다. 재생목록 정렬이 '수동'이면 재생목록 안에서는 날짜순 자리에 넣습니다.

6. 7일마다 유튜브 인증

구글 앱이 '테스트 중' 상태라서, 유튜브 인증은 인증한 날부터 7일 뒤에 만료됩니다. 앱 게시는 절차가 복잡하니 하지 않고, 대신 일주일에 한 번 '유튜브 인증' 버튼을 누르면 됩니다.

  • 만료 날짜는 프로그램 위쪽 '유튜브 계정' 칸에 항상 표시됩니다. 예: 인증 만료 10-03 20:50 (6일 23시간 남음). 하루 미만이 남으면 주황색, 만료되면 빨간색으로 바뀝니다.
  • 만료 전에 아무 때나 다시 인증하면, 그때부터 새로 7일이 됩니다. 예를 들어 매주 일요일에 한 번 누르는 식으로 습관을 들이면 편합니다.
  • 만료돼도 다운로드는 계속되고 업로드만 멈춥니다. 인증하면 밀린 영상을 순서대로 이어서 올립니다.
  • 6일째(만료 하루 전)부터 알림이 뜹니다. 프로그램이 켜져 있으면 트레이 알림과 "지금 인증할까요?" 창이 뜨고, 프로그램이 꺼져 있어도 자동 실행 중 윈도우 알림이 하루 한 번 뜹니다.
  • 다시 인증할 때도 '확인하지 않은 앱' 화면이 나옵니다. 똑같이 계속을 누르면 됩니다.

7. 화면 보는 법

채널 탭

채널이 두 개 이상이면 목록 위에 전체 | 채널A | 채널B 탭이 생깁니다. 탭을 누르면 그 채널 영상만 보이고, 탭 옆에 ▶ 올라가는 재생목록이 표시됩니다. 채널 관리에서 뺀 채널도 기록은 탭으로 남습니다(· 감시 안 함).

위쪽 네 칸

  • 네이버 쿠키: 네이버 로그인 상태(19+ 영상에만 필요).
  • 유튜브 계정: 채널 이름, 오늘 업로드 가능 여부, 인증 만료 날짜.
  • 자동 실행: 켜짐/꺼짐, 다음 실행 시각.
  • 처리 현황: 완료, 대기, 실패 개수.

창 오른쪽 위 ─ □ ✕ 왼쪽의 아래 화살표(트레이로 최소화) 버튼을 누르면 창이 숨고 트레이(화면 오른쪽 아래 시계 옆, ^ 안쪽)에 아이콘만 남습니다. 창의 일반 최소화(─)는 평소처럼 작업 표시줄로 내려갑니다. 트레이 아이콘을 클릭하면 다시 열리고, 우클릭하면 지금 실행 / 유튜브 인증 / 종료 메뉴가 나옵니다. 창을 닫거나 종료해도 자동 실행은 계속됩니다.

목록의 '상태'

상태뜻
대기받을 차례를 기다리는 중입니다. 게시되고 30분 뒤부터 받습니다.
다운로드중 / 다운완료·업로드대기받는 중이거나, 받아서 검증까지 끝낸 상태입니다.
업로드중 / 업로드완료유튜브에 올리는 중이거나 다 올린 상태입니다.
실패여러 번 시도해도 안 된 영상입니다. 메모 칸에서 이유를 확인하고 우클릭 → 재시도 또는 제외를 누르세요. 순서를 지키기 위해, 실패 영상을 처리하기 전까지 뒤 영상은 기다립니다.
보류(자동 대상 아님) / 제외채널 추가 전 방송이거나, 직접 뺀 방송입니다. 과거 방송은 5장 방법으로 올리세요.
유튜브에서 삭제됨 / 유튜브 영상 잘림유튜브 쪽 영상이 없어졌거나, 원본보다 짧거나, 처리에 실패한 상태입니다. 유튜브에서 지운 뒤 우클릭 → 다시 업로드를 누르세요.

상태, 유튜브 업로드, 썸네일 칸은 배경색으로도 구분됩니다. 초록은 완료, 파랑은 받기 완료(업로드 대기), 노랑은 진행 중, 빨강은 실패나 문제, 주황은 썸네일 미적용, 회색은 대기나 보류입니다.

썸네일 칸의 "기존 영상 · 확인 안 함"은 이 프로그램이 올리지 않고 유튜브에 이미 있던 영상입니다(재설치 등). 썸네일이 제대로 붙어 있으면 우클릭 → 썸네일 적용됨으로 표시, 없으면 우클릭 → 썸네일 적용을 누르세요. 자동으로 다시 올리지는 않습니다.

썸네일 칸은 치지직 썸네일이 적용됐는지 보여 줍니다. 12시간이 넘어 나눠 올린 영상은 파트마다 같은 썸네일이 들어가고 (1/2)처럼 표시됩니다.

메모 칸의 '파일 검증 ✓'은 받은 파일의 길이가 치지직과 같고 재생도 정상이라는 뜻입니다. '유튜브 길이 ✓'는 유튜브 처리 후 길이까지 확인됐다는 뜻입니다.

8. 자동 실행은 언제 도나

  • PC가 켜져 있고 윈도우에 로그인한 상태에서 30분마다 돕니다. 화면 잠금은 괜찮지만, 로그아웃하거나 절전 중이면 돌지 않습니다.
  • PC가 꺼져 있던 동안 올라온 방송은 켜진 뒤 방송일 순서대로 처리합니다.
  • 프로그램 창을 닫아도 자동 실행은 계속됩니다.
  • 방송이 끝나고 다시보기가 올라오면 보통 30분~1시간 안에 받기 시작하고, 20~40분 뒤면 업로드까지 끝납니다.

업데이트

  • 새 버전이 나오면 프로그램을 켤 때 위쪽 업데이트 버튼이 초록색 업데이트 (v1.x) ●로 바뀌고 트레이 알림이 뜹니다.
  • 버튼을 누르면 깃허브(github.com/beubeulling-sudo/chzztube)에서 새 파일을 받아 교체하고, 다시 켤지 묻습니다.
  • 설정·채널·기록·유튜브/네이버 인증은 그대로 유지됩니다(config.toml, data 폴더는 건드리지 않음). 바꾸기 전 파일은 data\backup에 보관됩니다.
  • 다운로드·업로드가 진행 중일 때는 끝난 뒤에 하세요.

9. 문제가 생겼을 때

증상해결
로그인할 때 "403 access_denied"구글 클라우드 → 대상 → 테스트 사용자에 그 계정 이메일을 추가하세요(3장 4단계).
"유튜브 인증 만료" / 업로드가 멈춤유튜브 인증을 다시 누르세요(6장).
"채널이 없습니다"그 구글 계정에 유튜브 채널을 먼저 만들고 다시 인증하세요.
"'데스크톱 앱'이 아님"클라이언트를 만들 때 유형을 데스크톱 앱으로 다시 만들어 JSON을 받으세요.
뒤 영상들이 계속 '대기'방송일 순서를 지키느라 앞 영상을 기다리는 중입니다. 앞 영상이 '실패'면 재시도하거나 제외하고, 19+ 영상이면 네이버 로그인을 하거나 제외하세요. 이유는 '로그' 탭의 "순서 유지" 줄에 나옵니다.
"업로드 한도 초과"유튜브 하루 업로드 한도입니다. 다음 날 자동으로 이어서 올립니다.
썸네일 "횟수 제한"유튜브가 채널 단위로 잠깐 막은 것입니다. 15분 이상 쉬었다가 자동으로 이어서 적용합니다. 연달아 수동으로 시도하면 제한이 길어질 수 있으니 그냥 두세요.
썸네일 "권한 없음"youtube.com/verify에서 전화 인증을 한 뒤 관리 → 썸네일 일괄 적용을 누르세요.
로그에 "치지직 원본 조각 손상"치지직 서버 쪽 조각 일부가 깨져 있던 것을 자동으로 처리했다는 뜻입니다. 그 지점이 1~2초 건너뛸 수 있지만, 뒤쪽 싱크는 유지됩니다.
재생목록 순서가 이상함재생목록 정렬이 '수동'일 때만 위치를 지정할 수 있습니다. 유튜브 스튜디오 → 재생목록 설정에서 바꾸세요.
디스크가 가득 참설정의 '업로드 후 로컬 삭제'가 켜져 있는지 확인하고, 관리 → 다운로드 폴더 열기에서 남은 파일을 확인하세요.
그 밖의 오류아래쪽 로그 탭이나 관리 → 로그 폴더 열기의 파일을 캡처해서 공유해 준 사람에게 보내세요. 로그에는 비밀번호나 열쇠 파일이 들어 있지 않습니다.

10. 꼭 지킬 것

  • 권리자(스트리머)의 허락을 받은 채널만 올리세요. 허락 없이 올리면 저작권 신고나 채널 제재를 받을 수 있습니다. 방송 속 음악이나 게임 화면 때문에 Content ID 소유권 주장이 붙을 수도 있습니다.
  • data 폴더와 client_secret JSON은 절대 공유하지 마세요. 프로그램을 남에게 줄 때는 처음 받은 zip을 그대로 주세요.
  • 프로그램을 지우려면 자동 실행 해제를 누른 뒤 폴더를 삭제하면 됩니다. 구글 권한까지 끊으려면 Google 계정 → 타사 액세스에서 앱을 삭제하세요.
